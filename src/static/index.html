If something looks off

Find what you're seeing, then try the fix next to it. Every change waits for Run classification, and older runs stay in the list to compare.

What you seeWhy it happensWhat to try
A class painted where it isn't (mines showing as plain barren, say) One class is covering two different things Split that class: a zoo model, or your own polygons
A split class mostly missed (low recall) Too few examples, or all from one corner Add polygons spread across the area, then train again

Split into finer classes

A Use a model from the zoo

Pick a trained model, then say what each of its classes means in your scheme.

B Build your own

One GeoJSON, a class on every polygon; the classes are read off the file. Example file · format

Standard format — a GeoJSON FeatureCollection in lon/lat (EPSG:4326). Every feature is a Polygon or MultiPolygon with "class": "<name>". Optional: "role": "negative" for "this is not that class", and a free-text "note". Everything else is ignored. At least two classes for a new split, and the polygons must fall inside the project's area.

or name the classes and draw them yourself

Train the split

Draw a polygon (⬠ on the map) and add it, or upload a file. A file with a class on each polygon fills every class; one without goes to the class picked above.
