Alpha Earth base map, with greenery split into acacia / non-acacia and barren into mining.

Draw a box on the map (▭ tool), or pick Custom and click the map to drop a centre — the slider sizes the box live.

Water uses a separate model on raw Sentinel for the chosen fortnight (5, 7), so it answers which pixels held water on that date, not the annual map above. Water frequency (#11) runs it over the whole year and counts how many fortnights each pixel was water — darker blue = more persistent water.

Segmentation vectorizes the mining pixels into discrete polygons (#4) — speckle dropped, tiny blobs filtered — so you get mining objects with per-segment area, not confetti.

Base classes and the inference year live in the Model Zoo — open it to pick a starting scheme or change the Alpha Earth year.

🌳 Hierarchy

Click any class to select it, then use the panel on the right to mark data or grow it. Selected: root

💾 Save / resume project

Save the whole project as one JSON — the class scheme, the sequence of steps that built it, plus the area, year and base classes. Datasets/models are kept as links, not copied. Load it to resume exactly where you left off.

🗂️ Model Zoo

Trained models + datasets, stored as cards in a git-backed catalogue.

Edit the tree, add example polygons, retrain a node — the 10 m map updates with the new sub-classes. Root-level retrain rebuilds the base map (slow). Trained models land in the Model Zoo as cards you can inspect and publish.

Pick a class

Select a class in the Hierarchy to see what you can do with it.

① Mark example data

Draw a polygon on the map, pick a role, then add — this is how you teach the model. Positive = "this is X"; negative = "not it".

…or upload a GeoJSON / KML of polygons

② Split into finer classes

Divide X into sub-classes. Bring your own data and train it, or apply a ready model from the zoo.

②′ Split by rule (no training)

Split X with an interpretable threshold on an index — if the rule holds → class A, else → class B. Evaluated live in Earth Engine, so it renders as crisp tiles with no data to mark.

Advanced: raw expression

Combine indices, e.g. ndvi_annual > 0.3 && slope < 5. Overrides the picker above when non-empty.

③ Add a class

Add a brand-new class under X.

④ Merge classes

Tick two or more leaf classes in the Hierarchy (even from different models), name them, and merge. A relabel layer applied after inference — no retraining. Active merges show in the tree with a ✕ to undo.

⑤ Retrain this split

Once X has children with example data, train the classifier that tells them apart.

The list depends on your inference data (#1): Alpha Earth is linear only, so the model renders as crisp tiles; Tessera adds Random Forest and other local models. “Auto” bakes off the valid models and keeps the most accurate (#17).

Tessera is available for the 4 requested test sites (#16). A Tessera split is trained + scored + carded, but doesn’t ride the crisp tile map (point-grid only).

Pool several Alpha Earth years so the split holds up across years (temporal robustness). Costs more time — one sampling pass per year.
